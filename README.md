**User Configuration Manager**

A Python project developed as part of the freeCodeCamp Python curriculum.

Project Overview:
This application allows users to manage configuration settings efficiently by adding, updating, viewing, and deleting settings.

Features:
  Add new settings
  Update existing settings
  Delete settings
  View all settings

Technologies Used:
  Python
  Functions
  Dictionaries
  String Manipulation
